# notes 目的

最終更新: 2026-08-30

## これは何

個人の学習内容をまとめる知識サイト。既存の [`atlas`](../../atlas) と同じ狙い(学んだことをコード化して蓄積・閲覧する静的サイト)を引き継ぐ後継プロジェクトだが、Atlasで最大の弱点だった**図解不足**を作り直すことを最優先の目的とする。詳しい経緯は[`02_lessons-from-atlas.md`](./02_lessons-from-atlas.md)を参照。

## 対象分野

- メイン: プログラミング・技術学習(言語、フレームワーク、アーキテクチャなど)
- 上記に限らず、学習した他分野の内容も扱う

Atlasのように「基本情報技術者試験」的な体系だけに限定せず、その時々で学んだことを幅広く置ける場にする。

## Atlasとの関係

- Atlasは廃止しない。既存コンテンツ・実装はそのまま参照可能な資産として残す
- notesはAtlasの構成・執筆方針を土台にしつつ、次の点を作り直す
  - 図解の作り方(本ドキュメント群の主題。[`03_diagram-policy.md`](./03_diagram-policy.md)参照)
  - Atlas自身が`docs/03detail-design/site-detail.md`§7に記録している構造面の教訓([`02_lessons-from-atlas.md`](./02_lessons-from-atlas.md)の「参考」節に転記)を初期設計から反映する
- 技術スタック(Next.js静的Export、`src/content/pages`+`routes.ts`+`nav.ts`の3層分離など)はAtlasの現行方式を踏襲する前提とし、変更する場合は本ドキュメント群を更新する
